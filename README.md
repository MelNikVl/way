# Путь маленьких шагов

Личный трекер на русском: доход, капитал, субъективное благополучие и посильные привычки. Работает локально, без аккаунта, внешних библиотек, телеметрии и отправки дневника на сервер.

## Запуск

Нужен Node.js 20 или новее. В папке проекта выполните `node server.mjs` (либо `npm start`) и откройте [приложение](http://127.0.0.1:4173). На Windows можно запустить `start.cmd`: он использует Node из PATH либо установленный runtime Codex.

Сервер слушает только `127.0.0.1`, порт 4173. Для другого порта задайте `PORT`. Закрытие процесса останавливает приложение. Повторное открытие на том же адресе и в том же браузере возвращает сохранённый дневник.

## Возможности

- «Сегодня»: состояние 0–10, энергия, смысл, сон, минуты работы над доходом, заметка и отметки привычек. Можно редактировать прошлые дни.
- «Мой маршрут»: неделя, месяц, полгода, год, пять лет. Критерии завершения, выбор двухнедельного эксперимента (карьера / услуга / продукт), недельные обзоры, внешние коммерческие результаты.
- «Привычки»: сигнал, минимальное действие, частота, пауза, собственные привычки. Без штрафов за прерванные серии.
- «Мой прогресс»: график настроения, доход, свободный денежный поток, чистый капитал, запас ликвидности; сценарий цели без предполагаемой доходности.
- «Узнать себя»: 56 необязательных вопросов, цель, валюта, личный/семейный охват, доступное время; экспорт JSON и восстановление с предыдущей копией.
- «На чём основано»: девять научных/официальных источников с датами, выводами и ограничениями.

## Данные и приватность

Дневник хранится в `localStorage` браузера, ключ `small-steps-v1`. Это не зашифрованное хранилище. Данные не синхронизируются между браузерами или устройствами. Удаление данных браузера удалит дневник: регулярно сохраняйте экспорт в личном месте. Экспорт содержит финансовые сведения и ответы.

`private/context.json` — необязательный локальный файл персонализации. Он исключён из Git. Содержимое и финансовые оценки из Notion не входят в публичный код. Без файла приложение открывает нейтральный профиль. Локальный сервер выдаёт этот файл браузеру; не публикуйте папку `private/` и не меняйте bind-адрес для удалённого доступа без отдельного решения об авторизации и хранении данных. При экспорте дневника первоначальная справка Notion и черновик активов не включаются: сохраняйте `private/context.json` отдельно.

Непрочитанные или повреждённые сохранения не перезаписываются обычными действиями. До импорта делается предыдущая копия; повреждённый оригинал отдельно сохраняется для скачивания. Ограничение импортируемого файла — 2 МБ.

## Как читать цифры

- Пустое поле означает «неизвестно», а не ноль. Нулевой доход/долг/оценка сохраняются как нули.
- Чистый капитал = стоимость учитываемых долей активов − обязательства. Доступные средства учитываются отдельно от недвижимости.
- Запас ликвидности = доступные средства / все месячные расходы. Это упрощённый ориентир, не персональная инвестиционная рекомендация.
- Все финансовые записи имеют одну валюту. После ввода финансов смена валюты блокируется, чтобы не переименовывать существующие суммы без конвертации.
- Семейная и личная цель задают охват записей. При смене охвата ранее введённые суммы надо пересмотреть вручную.
- Для суммы в иной валюте нужен курс на дату оценки. Автоматического валютного или инвестиционного прогноза нет.
- Для цели по капиталу рассчитывается требуемое пополнение и результат при текущем денежном остатке; для цели по доходу показывается разница с текущим доходом. Богатство и счастье не гарантируются.
- Средние состояния считаются по заполненным значениям за 7 дней; показываются количества наблюдений. Это авторские вопросы, не диагностические шкалы.
- Ритм привычек — доля выполненного от текущей частоты за последние 7 дней, ограниченная 100% по каждой привычке. Изменение частоты/пауза меняет текущий показатель; история плановых частот не моделируется.
- План на дальние горизонты — редактируемые через отметки ориентиры, не автоматически подтверждённые достижения. Анкета сохраняется для размышления; скрытого AI-анализа или автоматической перестройки всего плана из ответов нет. Выбор направления явно меняет двухнедельный план.

## Проверка

`node --test core.test.mjs` — тесты импорта, границ дат, пропусков и нулей, отдельных валютных/семейных параметров, капитала, денежного потока, ликвидности и сценариев цели. `node --check app.mjs` — синтаксис интерфейса.

Приложение состоит из `app.mjs` (интерфейс), `core.mjs` (валидация и расчёты), `content.mjs` (вопросы/маршруты), `evidence.mjs` (источники), `styles.css`. Сборка и установка пакетов не нужны. Сервер выдаёт только разрешённые файлы, не весь репозиторий.
